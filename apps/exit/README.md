运行[首页的一行安装命令](../../README.md)，先选“出口端”，再选版本。无人值守可在下载后的 bootstrap.sh 传入 `--role exit --version v0.3.1`。版本不会与另一种面板混在同一菜单中；安装器不会覆盖已安装的其他版本或角色。
