# 架构与当前状态

本项目仍是开发版本。当前先完成独立中转面板和出口面板；总控只预留数据契约，不开发总控服务。

## 进程与权限

Node.js 24提供同源HTTPS、密码学和SQLite。前端资源不依赖公共CDN。数据库保存账户、配置、审计、通知队列与累计统计；敏感配置使用本机主密钥加密。

网页、独立Hy2认证服务、统计与权限后台均以低权限账户运行。本机root管理器通过受限Unix套接字执行固定系统操作，不接受任意命令或路径。网页退出不撤销内核保护；管理器退出会停止本程序核心。统计后台退出会停止关联核心，卡住或持续失败则由120秒系统看门狗终止；按恢复策略重启，不允许长期无人统计运行。SSH底层急停可绕过网页和管理器直接执行。

四个协议/出口组合使用四个独立服务账户：VMess TCP直出、VMess TCP经ATT、Hy2直出、Hy2经ATT。官方Xray与Hysteria负责协议实现，本项目不另写协议核心。VMess保持原始TCP，不能将其描述为带域名证书的TLS协议；Hy2使用匹配域名的正式TLS证书。

## 路由与防绕行

WG仅接管明确的隧道账户，不替换VPS全局默认路由。nftables限制各账户的物理出站、WG出站、本地认证与统计接口；隧道账户另有unreachable策略路由作为失效拒绝。IPv6业务不能绕过IPv4线路限制。出口端仅允许明确配对的中转地址转发，并限制访问本机和保留地址。

只操作本程序的接口、公钥匹配、策略路由及带明确标签的防火墙规则。UFW存在且启用时添加必要规则，不启用、重置或接管个人已有规则。系统服务为UFW锁文件及配置提供必要写入例外，其他文件系统保护保留。

手动停止和急停由持久停止锁优先执行。旧启动、证书重载及后台权限重建不能清除更新的停止意图。自修复有重试上限和退避，不能无限重启。启动WG时检查真实接口与保护规则；服务仍active但接口缺失会重新执行网络服务，不能仅凭服务状态返回成功。协议核心退出等待上限10秒，避免故障恢复长时间卡在退出阶段。

## 用户与统计

Hy2独立认证实时检查启用、期限、额度及出口权限，撤销时使用kick处理现有连接。TCP权限变化会重建对应协议/出口实例，因此可能中断同一实例其他用户；页面明确提示该边界。

核心计数按运行周期去重并累计；长采样间隔不伪造实时速度。在线状态取连接观测，最后在线时间与最后流量活动分别记录。旧采样失效后显示未知，不能把节点失联当成用户离线。

线路周期累计独立于用户列表，按直出、经ATT两类出口汇总TCP与Hy2。北京时间自然月开启新周期，保留旧周期记录；不将网卡、WG封装与业务流量重复相加。采样中断跨月时只能按采样时间归属，突然断电仍可能损失最后一次采集后的尾部流量。

用户额度由周期采样执行，会有采样间隔内超额，不能宣传为逐字节实时扣费。有限额线路无法采集时停止相应实例。

## 配置、证书与维护

配置保存默认保持停止；配对变化使旧协议配置失效，保留填写内容供重新确认，不能运行新配对和旧协议的混合状态。同机角色切换归档角色账户与历史，保留全局管理连接，切换后保持急停。

域名证书通过ACME DNS-01和受限Cloudflare令牌自动签发、续签。证书与私钥按版本原子发布；验证记录带本次任务标记，加密日志支持进程中断后的定向清理。测试签发不能替换正式证书。

管理HTTPS端口或证书变更后进行实际自检，失败恢复旧连接。启用域名证书后保留安装时IP地址，改端口时同步更新两者；只接受明确登记的Host，同一请求的Origin必须与所用地址一致。IP访问域名证书可能出现名称不匹配提示，不宣称获得受信任的IP证书。通知发送失败不会撤销已经健康的新连接。Bark支持直接粘贴完整推送链接，自动提取地址与Key，保存后不回显链接中的Key。消息加密位于可选折叠设置；包含完整安全入口地址的通知必须加密，未设置加密时只发送不带地址的变更提醒。队列具有去重、冷却和有限重试。

普通配置与加密完整备份区分处理。导入保留本机身份和管理入口，复制模式重建用户凭证，恢复后要求确认配对。外观图片、告警阈值和归档角色用户包含在备份范围内。

安装器检测环境、校验固定组件下载、创建独立身份和systemd服务。保留数据卸载可恢复账户、入口、用户及累计；不卸载共享系统依赖。当前升级器支持同一运行时及协议核心的面板更新，组件摘要发生变化会明确拒绝，避免代码与二进制版本不一致。

## 验收证据与剩余边界

原有Linux后端83项回归通过。2026-11-25新增旧Hy2链接兼容后，Windows完整测试87项中84项通过、3项涉及证书、符号链接或Linux内核状态的用例留在Linux执行；本次变更相关18项在Linux另行通过。浏览器覆盖中转端与出口端的无窗口操作流程，51个源文件语法检查通过。具体机器地址、凭证、运行报告和截图只保存在忽略提交的本地目录，不进入源码包。

已完成实际核心业务请求与统计、Hy2独立认证及单用户撤销、隔离网络WG与UID防绕行、本机统计接口访问限制、低权限核心异常重启及手动停止、HTTPS端口变更与失败回退、保留数据卸载与恢复、正常手动回滚与损坏回滚目标的故障恢复测试。完整发布包升级已验证正常更新、坏版本自动退回、保留先前成功的回滚点，再手动回滚；使用非零用户用量校验账户与统计保留。原有Web服务和个人防火墙规则在共存验收中保留。

实际暂停统计后台会触发系统看门狗，关联核心随之停止，再依恢复策略恢复。内核规则测试包含表仍存在但链被清空的情形，能够检测规则不完整并恢复保护；不能只以表存在判断保护正常。

安装恢复已验证未完成安装、程序目录缺失两类故障。从独立源码目录恢复后，管理员、身份、入口、用户及累计保留，运行时目录不会被重复嵌套，管理服务恢复且代理保持急停。未提供升级过程突然断电时的自动回滚保证；必要时使用独立源码和保留数据恢复安装。

干净Debian12、Debian13隔离环境均已验证管理功能与整机重启后的登录、身份和入口持久性；Debian13完整协议矩阵仍待补充，尚未开放正式支持。真实域名已完成ACME测试签发、正式签发与管理HTTPS加载，证书链和域名验证通过，保留原IP访问并恢复原预览连接。Bark普通测试推送已获用户授权并确认手机收到；不等同于全部告警事件的真机验收。真实到期续签仍待验证。发布方案已调整为公开GitHub仓库与Release，线上下载链路仍需在仓库建立后验证，不能将模拟器通过当作外部生产验证。

同一宿主上的隔离网络与独立Debian12虚拟机已完成组合验收：通过两端面板API配对，官方VMess TCP、Hy2各走直出或WG出口，四条线路均实际传输并核对出口；Hy2客户端验证正式域名证书。真实用户与线路计数、在线观测、停用与额度拒绝已验证，其他用户仍可连接。删除WG后隧道线路拒绝连接、直出可用，恢复接口后客户端能够重连。出口虚拟机整机重启后WG自启，隧道业务恢复。测试结束恢复原面板账户、证书配置、用户和累计，关闭虚拟机及测试网络，宿主路由、防火墙和转发开关保持原样。

这属于单机隔离功能验收，不代表真实双VPS公网线路的延迟、吞吐、丢包或抗封锁表现。本次Hy2故障后重连检查等待约31秒，期间没有重启测试客户端；该数值仅表示本次恢复观察阶段的等待，不作为正常线路性能指标。

获得用户明确部署授权后，另完成两台中转与一台出口的现用环境安装和接管。保留两台中转原Hy2域名、端口、密码及直出/WG出口关系，从Windows官方客户端验证四条公网线路的证书与实际出口，用户统计记录到真实传输。旧单密码仅对明确导入且加密保存了兼容标记的用户生效，仍检查停用、额度、有效期和出口权限；重置凭证会取消兼容，重复的旧密码拒绝认证。普通新用户继续使用独立用户认证。旧服务、守护任务、旧WG和证书配置在备份及接管验证后清理。

现用中转还验证了删除WG接口后隧道UID无法联网、直出仍可用，以及重新启动网络后接口和正确出口恢复。生产环境此轮只启用原有Hy2线路，TCP作为已配置但停止的备用，不声称完成TCP公网矩阵、生产服务器整机重启或长时间压力验收。
