# 总控接入预留（协议草案 v1）

本阶段交付本机面板，总控服务、机器认证、远程配置、联网数据上报均尚未实现。现有程序不需要总控，也不会主动连接总控地址。

## 已有边界

`src/controller-contract.mjs`提供内部只读快照。`GET /<安全入口>/api/integration`需要有效管理员会话，返回contractVersion、稳定nodeId、本机角色、功能描述、采集时间、线路周期计数和后台健康状态。它是本机管理员的检查接口，不是可以直接暴露给总控的机器接口。

`GET /<安全入口>/api/line-usage`返回本机按出口合并的当前周期用量，并保留四个协议/出口组合的明细。计数单位bytes，速度单位bytes/second；fresh与observedAt说明状态是否新鲜。未采到速度用null，不能写成0或沿用过期速度。计数为用户业务流量，不与物理网卡或WG封装计数相加。

本机持久identity用于区分服务器，不能使用IP或服务器名称代替。改名、修改管理端口及安全入口轮换不更改identity。复制配置到新机器保留新机器自己的identity。

## 后续写入接口必须遵守

- 管理模式只有独立或受控；受控时用户相关本机写接口必须由后端拒绝，维护与急停保留。
- 接管、退出接管均需确认；撤销旧控制凭证。当前版本不接受切换为受控。
- 配置必须包含接管代次、递增版本和内容摘要。重复应用不重复执行，旧代次/旧版本不得覆盖新状态；完整校验后应用并确认实际结果。
- 总控期望版本与本机实际版本分别记录；没有应用确认就显示待同步，不能伪装成功。
- 所有系统变更仍经过现有固定操作的本机管理器，不能接受任意命令、文件路径或不受限核心配置。
- 机器认证与面板管理员、安全入口分离；未来专用监听默认关闭，不能以预留为由增加免登录管理路径。

## 后续上报接口必须遵守

- 实时速度和在线状态允许丢弃旧样本；界面标记数据时间，失联不伪装离线。
- 累计流量需本地持久待报、确认及幂等补报；核心重启标记新的计数周期，不能重复累计。
- 用户使用不变的内部编号；删除授权不转移、复用或清空旧用户历史。
- 受控面板不展示个人分析，但后台如需可靠个人统计，必须有最小采集与断联缓冲。
- 全局额度在断联期间如何执行、缓冲容量和保留期限，留待总控开发阶段明确，不在当前程序中假装已解决。

## 统计边界

当前线路统计按北京时间自然月、样本保存时间归属周期。采样中断横跨月界时无法准确还原每个字节的发生时刻；突然断电也可能损失最后一次成功采集后的增量。界面显示开始记录时间，不把新增统计功能之前的历史伪装成已完整计量。
