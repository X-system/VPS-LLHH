# AI辅助配置的后续边界

本文件记录后续需求。本版没有MCP服务、AI专用认证或可供新账号直接使用的自动配置包，不得把设计说明描述成已实现功能。

## 目标与方式

全新AI账号不依赖历史聊天，读取随面板版本发布的入门说明后，识别当前版本、角色、已完成步骤及仍需用户提供的信息。面板提供固定、版本化的配置操作；网页与自动配置共用参数校验和系统执行逻辑。常规配置不修改源码。

说明可封装为Skill，但同时保留普通操作文档，便于其他具备工具能力的客户端使用。MCP是可选适配层，不承担网络路由或协议核心。若客户端允许本地执行，可通过SSH通道连接同一配置接口；不能推断所有桌面聊天客户端都自带SSH能力。

## 预期交接材料

- 安装结果给出面板版本、说明位置与可复制的任务说明；不把密码或令牌放入任务文本。
- 提供可读取的能力描述和参数格式，说明哪些功能确实可用。
- 角色、配对、域名、证书、用户、统计、启停与恢复分别有操作顺序、成功条件及常见错误解释。
- 先读取当前状态，再检查参数、生成变更计划、执行和验收；已有配置不能当成空白机器覆盖。
- 同一任务重试不重复创建用户、配对或DNS记录，旧配置版本不能覆盖较新的状态。

## 接入和变更

SSH或MCP接入需要用户实际授权。未来应支持独立、可撤销、有限期的自动配置凭证；不借用安全入口作为API密钥，不共享总控或Cloudflare令牌。

MCP默认不向公网开放，可由桌面适配器通过SSH通道访问。所有系统变更仍由本机固定操作管理器执行，不提供任意命令、任意路径或修改程序源码的工具。

域名所有权、有效DNS令牌和服务器权限不能由模型凭空推断。私密值使用受保护的输入方式，不写进操作说明、聊天任务、普通日志或公开仓库。

配置和启动分别处理。先完成配对、证书与检查，保存后保持停止；只有已获准启动时才开启相应线路。手动停止、急停及断线保护对自动配置仍有效。

## 后续验收

使用没有历史上下文的新账号，按发布材料完成两角色配置；覆盖配置已存在、重复执行、版本不兼容、断线、部分应用失败、凭证撤销和恢复。验收前不能承诺完全无人值守或任意客户端都能理解并执行全部步骤。
