# 0.3.1

中转端与出口端分别发布 relay-v0.3.1、exit-v0.3.1。适用 Debian 12 amd64，保留所有历史版本的标签和安装包。

## 界面调整

- 按两端实际使用场景精简首页、用户管理、流量监控、服务配置与面板设置的重复文字，修正卡片、配置摘要和刷新控件的对齐。
- 首页统一显示网络速度监控；中转端显示在线用户、VPS实时速率和双向流量统计。VPS实时速率使用物理网卡采样，与用户业务流量分别统计。
- 用户在线情况显示在线、离线或从未上线；获配线路全部停止时显示离线。采集异常单独提示，不把监控故障当成离线。
- 出口端使用中转机状态、中转机通信状态等名称，按最近3分钟WireGuard握手汇总异常和正常台数。握手正常不代表所有网站必然可达。
- 移除临时暂停刷新按钮，恢复常规自动局部刷新。

## 更新管理

- 发现新版时直接展示版本与中文更新内容；手动检查后可点击蓝色版本号查看介绍。弹窗不再放日志导出按钮，日志保留在维护页面。
- 发布流程要求先编写对应版本说明，缺失时拒绝发布。
- Bark增加更新状态提醒，覆盖发现新版、高危版本、即将更新、开始、完成和失败，尊重原来的事件选择与关闭报警设置。
- 增加发行者紧急更新策略支持；本版未设为强制更新。普通更新可稍后处理或预约。
- 修复已有正式证书时保存访问设置仍保留旧IP主管理地址的问题，同时保留用户选择的IP访问权限。

升级保留账号、随机入口、证书、配对、用户与统计数据，以及原有线路启停状态；不自动打开已停止的备用线路。不改变代理协议、WG加密方式或用户线路权限。BBRX仍为实验性功能，尚未证明相比原版BBR的提速收益。

安装选择0.3.1；已有面板通过检查更新安装。当前更新器不支持同时更换Node或代理核心二进制，非Debian12 amd64环境未声明兼容。
