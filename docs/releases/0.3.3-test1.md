# 0.3.3-test1（测试版）

中转端和出口端分别发布relay-v0.3.3-test1、exit-v0.3.3-test1。适用Debian 12 amd64，历史版本及安装包保留。

- 修复精简系统没有curl时，第一条安装命令立即失败的问题：入口命令本身负责自动补齐curl、Python3与CA证书。
- 引导脚本完整下载并通过语法检查后才执行，不再通过管道运行可能不完整的下载。
- 安装器在第一次调用Python之前安装依赖；源码直接安装同样经过环境检查。
- 检查root权限、系统与架构、systemd和可用空间，再检查WireGuard及防火墙能力。不支持的环境明确报错，根目录或临时目录不足1GB时停止。
- 自动识别已安装的软件包，缺少的自动安装；软件源和下载有限重试，软件包锁最多等待120秒，不删除锁、不强杀其他安装程序、不自动卸载软件。
- 安装过程显示当前步骤。下载、软件源、依赖和系统能力等失败时显示中文原因、退出码和处理方向，不把失败当成功。
- 首页改为可在精简系统执行的完整入口命令；滚动入口标签v0.2.0仅为兼容下载地址，不限定实际安装版本。

已以模拟依赖与下载验证缺少组件、组件齐全、软件源失败、不支持的系统、空间不足及部分下载失败等十种情况；测试不安装真实软件。保留已有安装与恢复检查，本版仍需通过全新VPS实际安装验收，不能保证所有服务商网络与虚拟化环境均可用。

包含0.3.2全部功能，不改变代理协议、用户凭证或线路权限；不是强制更新。已安装用户使用面板更新，新机器运行首页命令后选择0.3.3-test1。
