# 0.3.0-test1（测试版）

适用 Debian 12 amd64 的中转端和出口端。分别发布 `relay-v0.3.0-test1` 与 `exit-v0.3.0-test1`，保留历史版本的固定标签、源码和安装包。总控端尚未开放安装。

- 中转端提供 Hy2直出、Hy2→ATT、TCP直出、TCP→ATT 四条线路的独立启停与实时状态；首页显示线路状态，出口端显示上游连接状态。
- Bark 支持系统／自定义两套模板、事件勾选、带宽与资源阈值、每项发送测试、预览、关闭和重新开启报警。自定义测试可使用未保存的文字；关闭会保留配置并取消未发送的消息。
- 故障通知可按配对顺序尝试代发；失败记录可查看，关闭报警后不继续后续代发。
- 更新来源内置，每天北京时间08:00检查；支持登录提醒、立即或预约更新、升级等待页、失败回退与日志导出。
- IP访问可独立开关；关闭前检查正式域名证书和解析，失败恢复原配置，SSH应急菜单可恢复IP访问。
- 证书卡显示北京时间到期时间和剩余天数，出口端提供可选的面板HTTPS证书入口。WG隧道不依赖域名证书。
- 简化重复标题、教程和菜单文字，刷新控件放在页面标题右侧；修复提示定位、交互反馈和手机布局。
- 服务灯采用可见的立体灯罩、高光与缓慢明暗呼吸，修正灯点和文字对齐。
- 管理员与备份密码只要求非空，不限制长度或字符组合；不会重置既有账户。
- 手动停止、急停和维护状态继续优先于自动启动／修复。升级后恢复升级前的启停意图，不自动打开原先停止的备用线路。

已完成后端回归、桌面与手机浏览器检查，以及 Debian 12 原生服务更新和恢复验证。本版仍是测试版，不代表全部系统或生产负载均已验收；BBRX仍为实验性功能，尚未验证相比原版BBR的提速收益。

新安装：运行仓库首页的一条安装命令，先选择中转端／出口端，再选择 **0.3.0-test1（测试版）**。已有面板使用“检查更新”，不要用首次安装脚本覆盖运行数据。

发布包仅含程序源码与公开依赖配置，不包含VPS凭证、Cloudflare/Bark密钥、私钥、实际用户数据或运维报告。
