# 0.3.2

中转端和出口端分别发布 relay-v0.3.2、exit-v0.3.2，适用 Debian 12 amd64。旧版本的标签、源码和安装包继续保留。

## 修复与调整

- 修复监控坐标字号被另一份样式覆盖为20px的问题，统一保持约13px，不再随卡片放大。
- 图表按照实际容器宽度重新计算坐标，首页桌面图表高度220px、详细图表230px，手机210px；宽屏不会把文字、曲线和高度整体拉大。
- 容器尺寸变化时自动调整图表，保留历史范围选择、曲线缺测留空、悬停查看数值及局部刷新。
- 补齐0.3.1界面文字调整：删除历史监控底部与出口表格的重复说明，协议摘要按原始TCP、Hy2排序，恢复设置按钮及自修复文案与参考图一致。
- 临时暂停刷新按钮不包含在本版，正常自动局部刷新继续启用。

## 安装与更新

新机器使用仓库首页的一条安装命令，先选中转端或出口端，再选0.3.2。已有面板使用检查更新；升级保留账号、入口、证书、配对、用户和流量数据，并恢复原来的线路启停状态。

本版包含0.3.1已有功能，不改动代理协议、WG加密、线路权限或节点凭证。不是强制更新版本。BBRX仍为实验性功能，尚未证实相比原版BBR的提速收益。

已检查1280、1920、2560宽度的图表字号与高度，并验证手机布局、范围切换及自动刷新。其他系统和架构尚未声明兼容。
