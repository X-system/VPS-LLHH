# 0.3.3-test2（测试版）

## 同版本修正：首次用户开通与配对反馈

- 中转端首次配置完成后直接弹出首个用户配置框。选择线路、额度和有效期，创建后自动显示订阅及导入链接；也可不创建用户，选择等待接入总控。选择持久保存，不伪装已连接总控。
- 读取请求遇到短暂网络中断自动重试；保存请求不重复提交。引导保存返回中断时，先恢复会话并核对后台进度，再继续已完成步骤。延长写入操作的等待时间，去掉未经确认的“可能正在重启”提示。
- 配对开始前检查出口已有中转名称，同名且身份不同会在两端提示更名；批准与落地配置前再次检查。冲突时不继续新增配对。
- 配对按钮立即显示处理中，双端显示已批准后的通信配置进度；进行中的配对不会因为切到另一标签页就主动暂停轮询，完成后引导自动下一步。
- 修复激活按钮悬停变白、白色文字看不清；“你好”改为约2.4秒上升渐显，保留系统减少动态效果的偏好。

验证包含：双面板真实浏览器配对和自动进入下一步、首个用户创建并展示订阅、总控模式选择、保存已生效但响应丢失的故障注入、读取连续两次断线后的恢复、同名配对拒绝及传输固定证书检查。

## 已安装面板的处理方式

- 修复新安装入口访问旧面板时找不到owned-artifacts.mjs、错误报告安装失败的问题。安装脚本登记使用本次校验后的源码，不依赖旧面板是否包含新模块。
- 检测到已有面板后，先选择“跳过”“覆盖安装（保留数据）”或“全新安装”。跳过立即结束；覆盖保留账户、用户、主密钥、配对、配置、证书和统计，只替换程序并保持线路停止；全新安装明确提示删除本机面板数据，必须输入DELETE并确认后才执行。
- 覆盖安装保留原服务器角色，禁止降级覆盖；全新安装重新选择角色并进入网页激活。不删除共享软件或其他程序。

中转端、出口端分别发布relay-v0.3.3-test2、exit-v0.3.3-test2。适用Debian 12 amd64。

- 修复环境检查直接读取/etc/os-release，将安装器VERSION变量覆盖成Debian版本的问题。这会跳过版本选择并出现“此版本尚未发布”错误；现在系统变量在函数内隔离。
- 增加含真实VERSION字段的环境回归，覆盖目标版本预设与未选择的情况。子进程失败不重复打印错误提示，所选版本不可用时直接显示中文原因。
- 安装菜单仅提供0.3.3-test2。旧版本源码、标签与发布包继续保留，不删除历史内容。
- 保留角色、版本、安装确认三步向导，输入错误可重试；取消与输入中断明确退出。
- 入口自动安装下载组件，安装器提前补齐依赖，验证系统、空间、WG及防火墙能力。最终检查四项管理服务和HTTPS入口，通过后显示面板地址及网页下一步。

已在PS的Debian 12全新面板环境执行真实安装，验证自动补齐unzip和wireguard-tools、网络能力、核心下载、管理服务启动及HTTPS检查。此前公开脚本的问题已在该机复现并修正。本版不宣称能修复所有服务商网络或虚拟化限制，遇到不可恢复问题会明确停止。

本版是测试版，代理默认停止；用户在网页完成配置后开启。ATT和YT没有因该测试被改动。

## 同版本修正版：首次激活、IP证书与彻底卸载

按用户要求继续使用0.3.3-test2，并替换当前测试程序包。原源码保存为archive归档分支或标签，旧程序包和校验附件保留为archive附件；本次修正版校验值与旧test2不同。

- 安装只输出首次激活链接，不显示临时用户名、密码。首次访问为“你好”欢迎页，点击“激活面板”后在网页创建管理账户，再继续配置。激活链接仍为独立随机一次性密钥，24小时有效；未设置账户时可通过llhh查看入口重新获取。
- 默认自动申请Let's Encrypt受信任的公网IPv4证书，使用shortlived证书和HTTP-01验证，需要TCP 80可从公网访问。不是自签证书，不通过HTTP明文提交密码；失败时明确报错，不停用其他占用80端口的服务。
- 增加IP证书自动续期任务，每天两次检查，并在到期前提前更新；证书地址、私钥和有效期均校验，续期时替换完整证书材料并重启网页服务。
- 引导底部使用统一的上一步和主按钮操作区，修复手机宽度溢出和进度显示；支持减少动态效果的系统设置。
- SSH菜单统一为llhh，第12项为“彻底卸载”。清理面板专用目录、账号、证书、服务、缓存、路由防火墙规则和已登记且未改动的临时下载脚本；不卸载共享软件包，不删除无关文件和共享系统日志。

验证：PS真机成功签发受信任IP证书；真实浏览器未设置忽略HTTPS错误，已完成欢迎、激活与网页创建账号。通过菜单12真实卸载后，面板专用目录、服务文件和命令入口均不存在；无关哨兵文件保留，dpkg软件包列表前后相同。中转与出口激活引导均有桌面、手机检查。代理默认停止；ATT和YT未因上述验证被改动。
