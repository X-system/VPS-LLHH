# 0.3.3-test2（测试版）

中转端、出口端分别发布relay-v0.3.3-test2、exit-v0.3.3-test2。适用Debian 12 amd64。

- 修复环境检查直接读取/etc/os-release，将安装器VERSION变量覆盖成Debian版本的问题。这会跳过版本选择并出现“此版本尚未发布”错误；现在系统变量在函数内隔离。
- 增加含真实VERSION字段的环境回归，覆盖目标版本预设与未选择的情况。子进程失败不重复打印错误提示，所选版本不可用时直接显示中文原因。
- 安装菜单仅提供0.3.3-test2。旧版本源码、标签与发布包继续保留，不删除历史内容。
- 保留角色、版本、安装确认三步向导，输入错误可重试；取消与输入中断明确退出。
- 入口自动安装下载组件，安装器提前补齐依赖，验证系统、空间、WG及防火墙能力。最终检查四项管理服务和HTTPS入口，通过后显示面板地址及网页下一步。

已在PS的Debian 12全新面板环境执行真实安装，验证自动补齐unzip和wireguard-tools、网络能力、核心下载、管理服务启动及HTTPS检查。此前公开脚本的问题已在该机复现并修正。本版不宣称能修复所有服务商网络或虚拟化限制，遇到不可恢复问题会明确停止。

本版是测试版，代理默认停止；用户在网页完成配置后开启。ATT和YT没有因该测试被改动。
