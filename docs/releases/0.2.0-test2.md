# 0.2.0-test2（测试版）

适用中转端、出口端，分别发布固定标签，不覆盖 test1。

- 修复 ATT 连接密钥标题与输入框焦点边框重叠。
- 修复 TCP 加速单选框被通用输入样式拉宽、标签被拆字的问题；手机允许整项换行。
- BBR／BBRX 的问号使用各自说明，去掉误用的配置导入提示；BBRX 继续标注实验性功能。
- 等待、成功和失败提示统一显示在操作按钮旁，取消页面顶部及底部的漂浮操作提示。关闭弹窗或离开页面不会把旧提示带到其他操作上。
- 修复服务状态浮层内容变化后可能超出手机屏幕的问题。
- 刷新时间统一改为“更新于 HH:mm:ss”。

已检查中转、出口两端的桌面与390px手机布局、错误重试、防重复提交和配对流程。此版本仍为测试版，不代表生产负载验收。

安装：运行仓库首页的一行命令，先选中转端／出口端，再选 0.2.0-test2。已有面板请使用升级流程，不要用首次安装脚本覆盖数据。
